# El Oyente

Un diario para aprender a escuchar música clásica: una obra al día, con su ficha, sus compositores e intérpretes, las épocas y un glosario. Se instala como app desde el móvil con «Añadir a pantalla de inicio».

- La web: `index.html` + `data/`.
- El contenido se escribe en `src/` y se genera con `python3 src/build_data.py`.
- Las instrucciones de trabajo para Claude están en `CLAUDE.md`.
- Publicado en https://el-oyente.com (Netlify publica solo con cada push a `main`).

Para añadir una obra, abre Claude Code en este repositorio y escribe: «Obra del día: <enlace>».
